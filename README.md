# Villalba Hnos. Implantes - Sitio Web Institucional

Este es el repositorio del sitio web de Villalba Hnos. Implantes, una plataforma moderna y profesional para la distribución de tecnología médica de vanguardia.

## 🚀 Características
- **Diseño Premium**: Estética moderna con tipografías Outfit y Raleway.
- **Multipágina**: Estructura organizada en Inicio, Empresa, Pacientes, Catálogo y Contacto.
- **Interactividad**: Animaciones suaves, filtrado de productos y formularios dinámicos.
- **Optimizado**: Totalmente responsivo y optimizado para SEO.

## 🛠️ Tecnologías
- HTML5 / CSS3 (Vanilla)
- Tailwind CSS (Layout & Utilitarios)
- JavaScript (Vanilla)
- Lucide Icons
